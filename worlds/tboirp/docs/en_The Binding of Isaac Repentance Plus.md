# The Binding of Isaac: Repentance+

## Where is the options page?

The [player options page for this game](../player-options) contains all the options you need to configure and export a
config file.

## What does randomization do to this game?

The most noticeable change is the complete removal of freestanding technologies. The technology blueprints normally
awarded from scanning those items have been shuffled into location checks throughout the AP item pool.

## What is the goal of Repentance+ when randomized?

There is only one goal at this time. Find a certain number of Co-Op babies to win.

## What items and locations get shuffled?

By default, all items that are normally locked when starting a new save file will be locked and shuffled. This can be
changed to include all items in the game. In that case, a random selection of items will start unlocked for you.

Locations are the typical conditions for unlocking secrets. Optionally, additional locations can be added, including
defeating specific bosses as any character, or completing each chapter as each character.
## Which items can be in another player's world?

Items, trinkets, characters, challenges, floors, consumable items, quest items can all be in others' worlds.

## What does another world's item look like in Repentance+?

Location checks are completing certain conditions. The item will be sent to the receiving player.

## When the player receives an item, what happens?

When the player receives an item (collectible, e.g. from the treasure room), it will be added to the item pool on the
next run. This also holds true for trinkets and pills. Every other item is immediately available within the
player's run.
